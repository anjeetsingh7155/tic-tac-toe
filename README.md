# 🎮 Tic-Tac-Toe

A clean, responsive Tic-Tac-Toe game with instant win/draw detection and a smooth user experience. Built for quick local play and easy extension.

---

## 🧰 Tech Stack

- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Editor:** Visual Studio Code (recommended with Live Server)

---

## 🚀 Features

- Two‑player local gameplay (X vs O)
- Instant win/draw detection with board highlight
- Game reset / play again
- Mobile‑friendly layout
- Simple, readable code structure for learning or extending
